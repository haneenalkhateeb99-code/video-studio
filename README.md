# Video Studio

مساحة عمل لإنشاء الفيديوهات باستخدام [Remotion](https://www.remotion.dev) (فيديو مكتوب بـ React).
يجري كل شيء في بيئة Claude Code السحابية، فلا تحتاج إلى حاسوب، والآيباد يكفي.

## بنية المشروع

| المسار | الوظيفة |
|---|---|
| `src/Root.tsx` | سجلّ الفيديوهات: كل فيديو مسجَّل فيه كـ `<Composition>` (المعرّف والمدة والأبعاد) |
| `src/HelloWorld.tsx` | الفيديو التجريبي (5 ثوانٍ، 1920×1080، 30 إطارًا في الثانية) |
| `src/PackedColumnLab.tsx` + `src/lab13/` | فيديو تجربة CMET205 Lab 13 (هبوط الضغط في عمود محشو) — المعرّف `PackedColumnLab13`، الناتج الصامت `out/packed-column-pressure-drop-lab13.mp4`، والنسخة بالتعليق الصوتي `out/packed-column-pressure-drop-lab13-voiceover.mp4`. نص التعليق في `docs/lab13-narration-script.md`، والصوت في `public/lab13/vo/` (يُولَّد بـ `scripts/lab13-tts.py`) |
| `src/fonts.ts` | تحميل خط Cairo (عربي + لاتيني) من الملفات المحلية |
| `public/` | الأصول: خطوط وصور وأصوات تُستدعى بـ `staticFile()` |
| `out/` | ملفات MP4 المُصدَّرة (محفوظة في المستودع لتتمكن من تنزيلها) |
| `remotion.config.ts` | إعدادات التصدير: H.264 و yuv420p، وهي صيغة تعمل على الآيباد والآيفون |

## تنزيل الفيديو على الآيباد

1. افتح المستودع في Safari على github.com (أو في تطبيق GitHub)، واختر الفرع الذي يحوي الفيديو.
2. ادخل إلى مجلد `out/` واضغط على الملف (مثل `hello-world.mp4`).
3. اضغط زر **Download** (أو "View raw")، فيُفتح الفيديو في Safari.
4. اضغط زر المشاركة ⬆️ ثم اختر **حفظ في الملفات** (Save to Files) أو **حفظ الفيديو** (Save Video) لإرساله إلى الصور.

> إذا كان المستودع خاصًا فيجب أن تكون مسجّلًا الدخول إلى GitHub في Safari، وإلا ظهرت صفحة 404.

## طلب فيديو جديد

اكتب لـ Claude في جلسة جديدة على هذا المستودع وصفًا مثل:

> أنشئ فيديو بعنوان "…" مدته 15 ثانية، مقاس عمودي 1080×1920 لإنستغرام، بخلفية زرقاء، يعرض النقاط التالية واحدة تلو الأخرى: …  ثم صدّره MP4.

حدّد ما يهمك من التفاصيل التالية:
- **المدة** و**المقاس**: أفقي 1920×1080 (يوتيوب)، أو عمودي 1080×1920 (ريلز وتيك توك وستوري)، أو مربع 1080×1080.
- **النصوص** واللغة والألوان والخط.
- **الصور أو الصوت**: ارفعها في المحادثة أو إلى مجلد `public/` في GitHub.
- **أسلوب الحركة**: ظهور تدريجي، أو انزلاق، أو تكبير، أو كتابة حرفًا حرفًا…

سيضيف Claude ملف مكوّن جديدًا في `src/` ويسجّله في `src/Root.tsx`، ثم يصدّره إلى `out/` ويرفعه إلى GitHub لتنزّله بالخطوات السابقة.

## أوامر (للبيئة السحابية)

```bash
npm install                                      # تثبيت الحزم (مرة واحدة لكل جلسة جديدة)
npx remotion render HelloWorld out/hello-world.mp4  # تصدير فيديو
npx remotion compositions                        # عرض قائمة الفيديوهات المسجّلة
npm run typecheck                                # فحص الأنواع
```

## مهارات Remotion لـ Claude

مهارات Remotion الرسمية (`remotion-dev/skills`) محفوظة في `.claude/skills/`، ويستخدمها Claude Code تلقائيًا في كل جلسة على هذا المستودع. التفاصيل وقواعد الاستخدام في `CLAUDE.md`.

## ملاحظات تقنية

- الخطوط محفوظة محليًا في `public/fonts`، لأن المتصفح المستخدم في التصدير داخل البيئة السحابية لا يستطيع تحميل الخطوط من الإنترنت مباشرة (فهو لا يثق بشهادة الوكيل الشبكي). لذلك لا تستخدم `@remotion/google-fonts`، بل نزّل ملف الخط إلى `public/fonts` بأمر `curl`.
- خط Cairo مرخّص برخصة SIL Open Font License (انظر `public/fonts/OFL.txt`). خط Public Sans (بديل مجاني لخط Aptos في عرض Lab 13) مرخّص بالرخصة نفسها (`public/fonts/PublicSans-OFL.txt`).
- تحتاج Remotion إلى رخصة شركة للشركات التي يعمل فيها 4 أشخاص أو أكثر، أما الأفراد فاستخدامها لهم مجاني. التفاصيل في [remotion.dev/license](https://www.remotion.dev/license).
